QADAM — ТАПСЫРМАЛАР КЕҢІСТІГІ

Бұл — Todo сайтының функциялары сақталған, дизайны бөлек жаңа нұсқасы.
Алтын түсті палитра, ашық/қараңғы тақырып, карточкалар және дөңгелек батырмалар.
Жоғарғы «Жаңа тапсырма» батырмасы бөлек терезе ашады.
Өңдеу — қалам белгісімен, өшіру — себет белгісімен көрсетілген.

Ашу: index.html файлын екі рет басыңыз. assets бумасы қасында болуы керек.
ZIP мұрағатын алдымен толық шығарып алыңыз.

1. Бет ашылғанда DummyJSON-нан алғашқы 30 тапсырма жүктеледі.
2. Негізгі беттегі «Жаңа тапсырма» батырмасы бөлек терезе ашады.
   Сол терезеде атау, орындаушының User ID-сі және статус таңдаңыз.
   «Қосу» POST /todos/add сұрауын жібереді. Тек сәтті API жауабы көрсетіледі.
3. «Өңдеу» терезесінде атау, статус және орындаушының User ID-сі өзгереді.
   «Сақтау» осы үш өрісті PATCH /todos/ID арқылы жібереді.
4. Құсбелгі статус өзгерісін PATCH арқылы жібереді.
   «Өшіру» DELETE /todos/ID сұрауын жібереді.
5. Орындаушының ID-сі Users API арқылы тексеріледі.
   Табылмаған ID кезінде қосу/өңдеу орындалмайды.
6. Орындаушының атын басқанда шағын суреті мен деректері, жанында
   оның барлық тапсырмалары ашылады. Осы бетте API қабылдаған
   жаңа тапсырмалар мен өзгерістер де көрсетіледі.
   Орындаушы ауысса, тапсырма жаңа орындаушының профиліне ауысады.
   Профильдегі «Жаңа тапсырма» батырмасы сол пайдаланушының ID-сін
   автоматты толтырады. «Өңдеу» әр тапсырманың астында орналасқан.
   Негізгі тізімге жүктелмеген тапсырманы да профильден өңдеуге болады.
   Қосқаннан/өңдегеннен кейін профиль жабылмайды және тізім бірден жаңарады.
   «Болдырмау» немесе Escape тек қосу/өңдеу терезесін жабады.
   API қатесі осы терезеде көрсетіліп, енгізілген деректер сақталады.
7. Алфавит бойынша сұрыптау негізгі тізімде бар; профильде жоқ.

ЛОКАЛДЫҚ САҚТАУ ЖОҚ
Тапсырмалар, өзгерістер және әрекеттер тарихы localStorage-қа жазылмайды.
Тақырыптың ашық/қараңғы таңдауы qadam-theme кілтімен бөлек сақталады.
Сайт тек DummyJSON-мен жұмыс істейді; JSONPlaceholder және еркін API таңдауы жоқ.
Сұрау қатемен аяқталса, тапсырмаға локалды өзгеріс жасалмайды.

DUMMYJSON ШЕКТЕУІ
DummyJSON — оқу API-і. Қосу, өңдеу және өшіруді еліктетеді,
бірақ өзгерістерді серверінде тұрақты сақтамайды.
Сәтті сұраудың жауабы бет ашық тұрған кезде ғана көрсетіледі.
Бетті немесе тапсырмаларды қайта жүктегенде сервердің бастапқы деректері келеді.
Тарих осы бет ашық тұрғандағы соңғы 100 сәтті әрекетті көрсетеді.
Бетті жаңарту тарихты тазартады.

Жаңа тапсырмаға қайтарылған ID серверде шын жасалмайды.
Сондықтан оны кейін PATCH/DELETE арқылы өзгерту немесе өшіру 404 қатесін
қайтаруы мүмкін. Сайт оны түсіндіріп көрсетеді және локалды амалға көшпейді.
Бірнеше POST бірдей ID қайтарса да, олардың жауаптары бөлек көрсетіледі.
Сервердегі бастапқы тапсырмаларды өңдеу/өшіру сұраулары қолданылады.
